# タバコ休憩マッチングアプリ (LINE版)

LINEグループ上で「今タバコ吸いたい」というタイミングが合った同僚同士をマッチングするアプリです。
会社のSlackなど社内システムは一切使わず、個人のLINEだけで完結します。
給料アプリ（salary-app）とも完全に独立したプロジェクトです。

## 使い方

1. 一緒にタバコ休憩する同僚とLINEグループ（または複数人トーク）を作る
2. そのグループにこのアプリのLINE公式アカウント（Bot）を招待する
3. 誰かがグループで **「タバコ」** と発言すると、Botが誘いメッセージを送信
   - **🚬 行く** : タップした人がその場でマッチング成立。グループに「✅ 〇〇さんが参加します！」と表示
   - **🕓 あとで**（会議中など） : グループに「🕓 〇〇さんは今忙しいみたいです」と表示され、その人には **🚬 今なら行けます！** ボタン付きメッセージが残る
   - 手が空いたら、そのボタンをいつでもタップすればマッチング成立として通知される
4. お誘いには有効期限があります（デフォルト20分、`REQUEST_TTL_MINUTES` で変更可）。期限切れ後にボタンを押すと「このお誘いは終了しました」と表示されます

LINEの「グループに参加している人だけが対象」という単純な仕組みなので、Slack版のような参加/脱退コマンドは不要です。グループのメンバー構成がそのまま通知対象になります。

## セットアップ

### 1. LINE公式アカウント（Messaging APIチャネル）を作成

1. https://developers.line.biz/console/ にログイン（LINEアカウントでOK、会社アカウント不要）
2. 新規プロバイダーを作成 → 「Messaging API」チャネルを作成
3. チャネル基本設定から **チャネルシークレット** を控える（`LINE_CHANNEL_SECRET`）
4. Messaging API設定タブから **チャネルアクセストークン（長期）** を発行して控える（`LINE_CHANNEL_ACCESS_TOKEN`）
5. 同じ画面で以下を設定
   - **Webhookの利用** : ON
   - **応答メッセージ** : OFF（Bot標準の自動応答と競合しないように）
   - **あいさつメッセージ** : OFF（任意）
6. LINE公式アカウントマネージャー（https://manager.line.biz/ ）の「応答設定」で
   - **グループ・複数人チャットへの参加を許可する** を ON にする（これをONにしないとグループに招待できません）

### 2. サーバーをデプロイして公開URLを取得

Slackと違い、LINEのMessaging APIは常時アクセス可能な公開HTTPS URL（Webhook）が必須です。
Render / Railway / Fly.io など無料枠のあるホスティングか、社外の任意のサーバーにデプロイしてください。
開発中に手元で試す場合は `ngrok` などでトンネルを張ると簡単です。

```bash
npm install
cp .env.example .env
# .env に LINE_CHANNEL_ACCESS_TOKEN / LINE_CHANNEL_SECRET を設定
npm start
# 別ターミナルで: ngrok http 3000
```

### 3. WebhookのURLを登録

LINE Developersコンソールの「Messaging API設定」→「Webhook URL」に
`https://<デプロイ先のドメイン>/webhook` を設定し、「検証」ボタンで疎通確認する。

### 4. グループに招待して動作確認

同僚とのLINEグループに公式アカウントを招待し、「タバコ」と発言してみてください。

## データの保存について

お誘いの状態は `data/db.json` にシンプルなJSONファイルとして保存されます（外部DB不要）。
このファイルは `.gitignore` 済みです。サーバーを再起動しても直近の状態は保持されますが、
デプロイ先がファイルシステムを永続化しない環境（一部のサーバーレス等）の場合は再起動で消える点に注意してください。

## 今後の拡張アイデア

- リッチメニューに「🚬タバコ」ボタンを置いて発言不要にする
- 複数グループ運用時に、グループごとの通知オン/オフ設定
- マッチング履歴の集計（誰とよく一緒に行くか等）
